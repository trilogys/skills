# GLOBAL MENTOR SETTINGS

> User-level defaults. A current request or project config can override these.

- Default mode: `/normal`
- Default mentor level: `L1`
- Preferred explanation language: Follow current conversation
- Global profile updates: Explicit `/profile` or `/monthly` only
- Maximum normal-mode learning targets: 1
- Store proprietary project detail globally: No
- Default learning export format: `md`
- Default learning export scope: Project
- Learning report timezone: Local system timezone
- Automatic learning report exports: No
- Preserve canonical Markdown when exporting other formats: Yes
- Career direction: Not set

## Notes

- `L1` means work first: complete routine code, highlight one high-value decision, and keep teaching brief.
- Change global profile updates only when you intentionally want automatic evidence writeback.
- Enabling automatic exports is a separate opt-in from profile updates; keep it disabled unless periodic files are explicitly desired.
