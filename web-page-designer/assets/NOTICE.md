# Visual Reference Assets

The PNG files in this directory are reference screenshots supplied for visual calibration. They help agents study surface balance, typography weight, radius relationships, spacing, icon treatment, and accent distribution.

They are not production UI assets or page templates. Do not copy the depicted brands, trademarks, text, metrics, navigation, or business layouts into generated products.

Third-party brands and depicted interfaces remain the property of their respective owners. Unless separately documented, these PNG reference files are not covered by the repository's Apache-2.0 license.
